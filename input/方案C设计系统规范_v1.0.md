# 方案C 设计系统规范 v1.0

**适用**：Hearten 同心互联产品画册 · A4 横版 297×210mm · 全中文 · 双品牌 · 仅 PDF
**依据**：planC.png 实测反推（非重新设计）；实测基准 = 画布宽对应 297mm
**状态**：可直接实现 —— 代码工程师无需追问即可照此排出任意 SKU 页面

---

## 一、Design Token

### 1.1 颜色

| Token | 色值 | 用途 |
|---|---|---|
| `paper` | `#FFFFFF` | 纸白底，全册唯一底色 |
| `ink` | `#141414` | 主文字、右栏黑块 |
| `body` | `#3C3C3C` | 正文 |
| `muted` | `#7A7A7A` | 次级信息、图注、英文小标签 |
| `hair` | `#D6D6D6` | 细分隔线 |
| `accent` | `#E4371F` | **版式强调色**：红色竖线、编号、标签、Power 标签 |
| `brand-orange` | `#F07321` | **仅限 Hearten Logo 本体**，不用于任何版式元素 |

> **两个橙不混用**：`accent` 只做版面结构，`brand-orange` 只出现在 Logo 里。二者永不在同一视觉层相邻出现。

### 1.2 字体

| 用途 | 目标字体 | 本机替代 | 字重 |
|---|---|---|---|
| 中文 | 思源黑体 SC | PingFang SC | Semibold / Medium / Regular |
| 拉丁·型号大字 | Inter Tight / Neue Haas Grotesk | Helvetica Neue | Black / Bold |
| 拉丁·小标签 | 同上 | Helvetica Neue | Medium |

**型号大字用拉丁字体**（A7、CR208、TBK06），中文品名用黑体 —— 二者字号差约 2.4 倍，保证"型号先入眼"。

### 1.3 字号阶梯（pt / 行高 mm）

| Token | 字号 | 行高 | 字重 | 用途 |
|---|---|---|---|---|
| `display` | 46–54 | 16.3 | Black | 型号大字 |
| `h1` | 30 | 12 | Semibold | 页标题（品牌与技术） |
| `h2` | 15 | 7 | Semibold | 中文品名 |
| `h3` | 13 | 6 | Semibold | 区块标题 |
| `lead` | 12 | 6.5 | Medium | 引导句 |
| `body` | 9.5 | 5.2 | Regular | 正文、参数条 |
| `spec-num` | 20 | 8 | Black | 右栏数值 |
| `spec-unit` | 9 | — | Medium | 数值单位 |
| `label` | 7.5 | 4 | Medium | 全大写小标签（字距 +0.18em） |
| `caption` | 7.5 | 4 | Regular | 图注 |
| `micro` | 6.5 | 3.5 | Regular | 页脚（字距 +0.10em） |

**印刷下限**：正文 ≥9pt；最小字号 6.5pt（仅页脚）。

### 1.4 线宽

| Token | 值 | 用途 |
|---|---|---|
| `rule` | 1.1 mm（≈3.2pt） | 红色强调竖线 / 封面横贯线 |
| `hair` | 0.25 mm（≈0.7pt） | 次级分隔线 |
| `table-head` | 0.4 mm | 表头下框 |

### 1.5 版面与网格

```
页宽 297mm  |  页高 210mm  |  出血 3mm  |  安全边 5mm
左边距 11mm
红色竖线 x = 104mm（通高，含出血）
右数据栏 x = 241.3mm，宽 55.7mm（贴右出血）
右栏黑块高 53.6mm
左栏文字起点 = 11mm，左栏有效宽 ≈ 88mm
中栏（产品图区）= 114mm → 234mm，图区宽 120mm
```

12 栏换算：`列宽 19.25mm / 间距 4mm`，供 CSS Grid 使用。

## 二、M1–M4 母版规范

### M1 封面
- 顶部左：Hearten Logo（高 12mm）；顶部右：`HEARTEN CATALOG 2026`（7.5pt，muted，字距 +0.18em）
- y=74mm 红色细线横贯出血
- y=84mm：`HEARTEN`（54pt Black）；y=110mm 中文副题（16pt）；y=124/132mm 品类与市场信息（9.5pt muted）
- 底部 y=168mm 细分隔线；左下"瑜伽与健身周边由 Ellylife 出品"，右下 Ellylife Logo（高 6mm）
- **Hearten Logo 只出现一次**（顶部）；封底才双标并列

### M2 单品页（主力版式）
三栏非对称：左栏信息 / 中栏产品图 / 右栏数据
- **左栏**：品牌标签（`HEARTEN ▪ / SERIES 01`）→ 型号大字（46pt）→ 中文品名（15pt）→ 卖点 01/02/03（编号 accent 色，标题 11.5pt，副句 8.5pt muted，每组间 0.25mm 细线）→ 底部认证徽章行（框线 0.3mm，距底 12mm）
- **中栏**：左上 `图注 / FIG. 01`（7.5pt muted，字距 +0.18em）→ 产品图（**印刷宽 ≥100mm**，垂直居中偏上）→ 底部图注 + 参数条（居中，8pt）
- **右栏**：首格黑底（`POWER` accent 标签 + 数值 20pt 白字 + 单位）；以下白底格（muted 标签 + ink 数值 + muted 单位），格间 0.25mm 细线；底部页脚 `HEARTEN CATALOG 2026` + 页码
- **Ellylife 变体**：左栏品牌标签改为 `ELLYLIFE`，右栏底部加 Ellylife Logo（高 4.2mm）；**认证位留空**（瑜伽品类不适用 CE/FCC/UL/ETL/PSE）

### M3 系列/对比页
- 左栏：品牌标签 → 型号大字 → 中文品名 → accent 色副标（有刷/无刷）→ 引导句 → 底部两个版本功率对照（竖排）
- 右侧内容区（x 114→234mm，宽 **120.3mm**）：上排两机型并排（各占半宽，图高约 84mm）+ 下方对比表
- **对比表规范**：表头 8.5pt Semibold + 0.4mm 下框线；行高 7.8mm；行间 0.25mm 细线；首列 ink，数据列 body；**缺测值填 `待补`（muted 色），不得留空、不得估算**
- 表格**不得跨越红色竖线**（竖线是栏分隔，不是装饰）

### M4 品牌/技术页
- 左栏：品牌标签 `/ ABOUT` → 页标题（30pt）→ 品牌引言（9.5pt）→ 认证体系（徽章 + 说明，5 项）→ OEM/ODM 能力（4 条）
- 右栏：Hearten 标 + 名称 + 定位 → Ellylife 标 + 名称 + 定位 → 细分隔线 → SPU 23 / SKU 108 / SPU PAGES 19 → 页脚

## 三、双语与标注规则（全中文）

- 画册**全部中文**，双语规则作废
- **保留拉丁原样**（不算英文文案）：型号（A7、CR208、TBK06）、单位（W / kPa / mm / kg / dB / pcs / min / cm）、认证代码（CE / FCC / UL / ETL / PSE）、品牌名（Hearten / Ellylife）
- 图注格式：`中文图注 / FIG. 标注`，FIG 标注用拉丁字体 + 字距 +0.18em
- 页码：`P.01` 起，位于右栏底部

## 四、线条与留白统一规则

1. **红色竖线**全册同一 x 位置（104mm），通高含出血，**任何文字与表格不得压线**
2. **细分隔线**统一 0.25mm、两端缩进对齐栏边界（左栏线右端 = 左栏文字宽 90mm）
3. **跨栏顶标签共基线**：各栏顶部标签（品牌标签/图注/FIG）统一 y=14–15mm 同一基线
4. **页脚保留边距**：页脚文字距页面底边 7–12mm，不贴边
5. 卖点组间距 16.5mm，组内标题→副句 6.4mm

## 五、文字溢出规则

- 中文品名：单行，超出左栏宽（88mm）则缩小至 13pt；仍超出则换行，最多 2 行
- 卖点副句：单行，超出 88mm 省略；**不得缩到 8pt 以下**
- 参数值：`spec-num` 超出右栏宽时降至 16pt；单位始终与数值基线对齐（数值底部 +13.2mm）
- 对比表单元格：超出列宽则换行，行高自适应 +2mm 步进
